## Life Cycle Assessment

In this project, I will be tracking the entire life cycle of beef. 
This will include tracking emission of the following greenhouse gases

| Greenhouse gas | Chemical formula |
| :--------------| :----------------|
| Carbondioxide | CO2 |
| Methane | CH4 |
| Ozone | O3 |
| Nitrous Oxide | N20|

We will be tracking the following stage:

- Production
- Transportation
- Consumption
- Waste
